# Запуск Smart Qora

Smart Qora подсчитывает проходящих через ворота животных по видеопотоку и показывает результаты в веб-панели. Самый простой способ запустить проект — Docker Compose.

## Быстрый запуск

Понадобятся:

- Git;
- Docker Desktop (Windows/macOS) или Docker Engine с плагином Docker Compose (Linux);
- NVIDIA GPU и NVIDIA Container Toolkit для запуска модели на GPU.

Склонируйте репозиторий и запустите контейнеры из каталога проекта:

```bash
git clone https://github.com/RuslanHinizov/Smart-Qora.git
cd Smart-Qora
docker compose up -d --build
```

При первой сборке Docker загрузит базовые образы и зависимости, поэтому запуск может занять несколько минут. Проверить состояние контейнеров можно командой:

```bash
docker compose ps
```

Откройте в браузере **http://localhost:5173** и войдите с начальными данными:

- логин: `admin`
- пароль: `admin`

В конфигурации по умолчанию приложение использует демонстрационную видеозапись и модель, включённые в репозиторий. PostgreSQL инициализируется автоматически, а миграции базы данных запускаются при старте backend.

## Если нет NVIDIA GPU

Для запуска на CPU откройте `docker-compose.yml` и удалите блок `deploy:` целиком из сервиса `backend` (включая вложенные `resources`, `reservations` и `devices`). Затем пересоздайте контейнеры:

```bash
docker compose up -d --build
```

На CPU обработка видео будет значительно медленнее. Если вы создали `backend/.env` из примера, установите в нём `DEVICE=cpu` и `REQUIRE_CUDA=false`.

## Подключение своей камеры

После входа откройте страницу камер и добавьте источник видео: RTSP-адрес, USB-камеру или файл. Выберите активную камеру и задайте линию подсчёта в редакторе камеры. Для RTSP укажите адрес вида:

```text
rtsp://пользователь:пароль@адрес-камеры/поток
```

Демонстрационная конфигурация уже содержит камеру с видеозаписью. Для настройки параметров самого первого запуска можно создать `backend/.env` из `backend/.env.example`; значения источника видео и линии из этого файла используются только при первоначальном создании камеры.

## Настройка для реального использования

Начальные логин и пароль предназначены только для демонстрации. Не используйте их на сервере или в сети, доступной другим людям. Создайте корневой файл `.env` на основе примера и задайте собственные случайные секреты:

```bash
cp .env.example .env
```

В `.env` замените `POSTGRES_PASSWORD`, `SECRET_KEY` и `ADMIN_PASSWORD` на уникальные значения. На Windows файл можно скопировать вручную или выполнить в PowerShell:

```powershell
Copy-Item .env.example .env
```

После изменения конфигурации запустите приложение заново:

```bash
docker compose up -d --build
```

Администратор создаётся только при первой инициализации базы данных. Если база уже создана, изменение `ADMIN_PASSWORD` в `.env` не меняет пароль существующей учётной записи. Меняйте пароль администратора в приложении.

Для доступа к панели извне настройте HTTPS и удалённый доступ отдельно. Включайте `COOKIE_SECURE=true` только когда браузер подключается по HTTPS. Не публикуйте порт приложения в интернете без защищённого удалённого доступа и надёжных паролей.

## Полезные команды

Посмотреть журналы:

```bash
docker compose logs -f
```

Остановить контейнеры, сохранив базу данных:

```bash
docker compose down
```

Снова запустить:

```bash
docker compose up -d
```

Данные PostgreSQL хранятся в Docker-томе `postgres_data`. Команда `docker compose down -v` удаляет этот том и данные базы; используйте её только если действительно хотите полностью сбросить базу.

Обновить проект до последней версии:

```bash
git pull
docker compose up -d --build
```

## Локальная разработка без Docker

Для backend нужны Python 3.12+ и PostgreSQL; для frontend — Node.js 22+. Настройте переменные backend в `backend/.env`, установите зависимости и выполните миграции:

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell:
# .venv\Scripts\Activate.ps1
pip install -r backend/requirements.txt
cd backend
alembic upgrade head
uvicorn app.main:app --reload
```

В другом терминале запустите интерфейс:

```bash
cd frontend
npm ci
npm run dev
```
